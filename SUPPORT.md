# Support

- Use GitHub Discussions for usage questions, deployment notes, and community ideas after Discussions is enabled.
- Use GitHub Issues for reproducible bugs and narrowly scoped feature requests.
- Use the private vulnerability-reporting flow for security concerns; do not disclose them in public issues.

This project is maintained by volunteers. Please include the Taffy version, operating system, Python version, deployment mode, relevant configuration keys with values redacted, and a minimal reproducible example.
