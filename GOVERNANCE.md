# Governance

Taffy is a community-maintained project with a primary maintainer responsible for releases, security response, and final integration decisions.

## Decision making

- Routine changes are discussed and reviewed in public pull requests and issues.
- Significant changes to storage format, trust boundaries, data-source policy, supported Python versions, or licensing require a design note and maintainer approval.
- Security reports and private user data are handled through private channels only.
- The primary maintainer may make time-sensitive release or security decisions, then document the rationale publicly once it is safe to do so.

## Maintainer expectations

Maintainers keep CI and dependency locks healthy, review contributions consistently, publish release notes, protect credentials and user data, and state uncertainty rather than fabricate data. Additional maintainers are added based on sustained, constructive contributions and an explicit willingness to share these responsibilities.

## Transparency

Public decisions belong in issues, pull requests, release notes, or discussions. Private operational material, credentials, production chat records, and vulnerability details do not belong in the repository.
