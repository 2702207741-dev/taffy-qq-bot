# Public-history note

This open-source edition begins with a deliberately clean Git history. The pre-public development workspace contained private configuration, runtime data, internal planning, and diagnostics that are not appropriate to publish or to preserve in an immutable public history.

The release package retains the current application source, tests, lock files, and user-facing operational documentation while excluding those private artefacts. The public project should build its own transparent history through reviewed pull requests, issue triage, releases, and CI evidence from this baseline onward.
