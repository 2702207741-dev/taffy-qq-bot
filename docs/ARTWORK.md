# Artwork provenance

The public edition uses `desktop/frontend/assets/logo.svg`, a simple geometric
speech-bubble and T mark drawn directly for this project on 2026-09-21. It is
distributed under the repository's Apache-2.0 license. It does not use the
previous character portrait or a reference image. No trademark exclusivity or
independent legal clearance is claimed.

The maintainer could not confirm redistribution rights for the previous PNG,
ICO and SVG artwork and requested replacement. Those files must not be included
in the public source tree, release archive or public Git history. The desktop
tray uses its native programmatic status icon; executable builds use the
packager's default icon unless the maintainer supplies separately licensed art.
